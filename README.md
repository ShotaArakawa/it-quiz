# IT資格ドリル(it-quiz)

IT系資格向けの4択問題演習アプリの雛形。解いたらすぐ解説を表示し、間違えた問題は自動で復習リストに入る。

## 概要

- 問題セットを選んで4択で解く → 正誤と解説をその場で表示 → 最後に結果
- 間違えた問題は「復習リスト」に溜まり、**2回続けて正解すると外れる**
- 分野別の正答率を苦手な順に表示
- ブラウザ内で完結(学習記録は localStorage)。サーバー費用なしで公開できる

問題はすべてこのリポジトリ用に書いたオリジナル問題。市販の問題集や過去問の文面は使っていない。

## 想定ユーザー

- 基本情報技術者・情報セキュリティマネジメントなど、IT系資格の受験者(学生・新人エンジニア・非エンジニア職)
- 通勤中などのすきま時間に、スマホで数問ずつ解きたい人
- 「間違えた問題だけ解き直したい」が、紙の問題集だと管理が面倒な人

## MVPの機能

| 機能 | 雛形の状態 |
| --- | --- |
| 問題セット一覧・選択 | ✅ 2セット(無料・有料見本) |
| 4択の出題・採点・解説表示 | ✅ 出題順はシャッフル、キーボード操作(1〜4 / Enter)対応 |
| 結果画面(得点・間違えた問題・解き直し) | ✅ |
| 間違いの記録と復習モード | ✅ 間違えた回数が多い順に出題、2回連続正解で卒業 |
| 分野別の成績 | ✅ |
| 有料セット(お試し問題数の制限) | ✅ 購入はモック(ボタンで解放、課金なし) |
| 広告枠 | ✅ プレースホルダのみ(結果画面) |
| ログイン・端末間同期 | ❌ 未実装(`ProgressStore` を差し替える) |
| 問題データのサーバー管理 | ❌ 未実装(今は `src/data/sets.ts`) |

## 構成

- Vite 6 + React 18 + TypeScript の静的サイト(ハッシュルーター)。Cloudflare Pages にそのまま置ける
- `src/lib/quiz.ts` … 採点・記録・復習順・集計の純粋関数(`node --test` でテスト)
- `src/lib/store.ts` … 学習記録の保存先インターフェース `ProgressStore`(今は localStorage)
- `src/data/sets.ts` … サンプル問題。`validateSet()` で入力ミスを検査できる

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト(Node 22.6 以上。型注釈をそのまま実行する)
npm run build    # 型チェック + 本番ビルド
```

## 収益化案

1. **広告**: 結果画面・トップのみに表示(解答中は出さない)。SEO流入の無料ユーザー向け
2. **有料問題セット**: 分野別・試験別のセットを買い切り(例: 1セット 480〜980円)。お試し数問は無料
3. **広告非表示 + 全セット見放題のサブスク**(例: 月 300〜500円)。試験直前期の需要を狙う
4. 将来: 企業の新人研修向けに、受講者の進捗を見られる管理画面(法人プラン)

## 集客案

- **SEO**: 分野・用語ごとに「1問だけ解ける解説ページ」を静的生成し、検索から演習へ誘導(例: 「稼働率 直列 計算」)
- **X / Threads**: 「今日の1問」を画像で毎日投稿し、答えと解説はアプリへのリンクで
- **Qiita / Zenn**: 苦手分野の解説記事から該当セットへ誘導
- 試験日の1〜2か月前に合わせた告知(申込期間・直前期)
- 学生向けに、情報系の学科・サークルでの紹介
